# 功能与使用说明书

> NetworkRadio v0.7.2 · ESP32-S3 网络收音机

## 一、开机与首次配网

1. 上电后屏幕显示开机画面，固件自动尝试连接已保存的 WiFi（最多记忆 5 组）；
2. **没有任何已存 WiFi 时**自动进入配网模式：
   - 屏幕切到**配网指导页**，显示热点名和配置页地址；
   - 手机连接热点 **`Radio-XXXX`**（XXXX 为芯片 MAC 后 4 位，无密码）；
   - 浏览器自动弹出（或手动访问）**http://192.168.4.1**，选择家里 WiFi 并输密码；
   - 热点仅支持 **2.4GHz** WiFi（ESP32 硬件限制）；
3. 配置成功后自动重启联网，并恢复上次播放的电台；
4. 手动进入/退出配网：**长按 BOOT 键 5 秒**，或串口发 `wifi portal` / `wifi portal off`。

- 列表**自动跟随**当前台滚动；

- **无操作自动熄屏**（默认 10 秒，节电护屏）：任意旋钮/按键操作或串口输入立即点亮，熄屏时长可配置——串口 `dim <秒>`（0=常亮），设置掉电记忆。

### 信息页（K0 长按 1 秒进入）

显示：固件版本 / 复位原因 / WiFi 名称与信号 / IP / 开机时长 / 内存 / 断流自愈统计 / 当前电台 / 码率 / 控制台地址。
内容超出一屏时**旋转旋钮滚动查看**，右上角显示滚动进度（如 `3-13/13`）。

### 配网指导页（配网模式自动显示）

大字显示热点名 + 配置页 IP，按屏幕提示操作即可。

## 三、旋钮与按键

| 操作 | 功能 |
|---|---|
| **旋转** | 选台：列表高亮实时跟随，**停手 0.25 秒**后自动播放（快速连转只切一次，不卡顿） |
| **按住旋转** | 调音量（无需先切模式，按下即调） |
| **长按旋钮 1 秒** | 锁定音量模式 / 解锁（不想一直按住时用；5 秒不旋转自动退出） |
| **旋钮短按** | 暂停 / 继续；停止状态下按 = 播放当前台 |
| **K0 短按** | 静音切换（屏幕显示红色"静音"） |
| **K0 长按 1 秒** | 主页面 ↔ 信息页 |
| **BOOT 短按** | 下一台 |
| **BOOT 长按 5 秒** | 进入 / 退出配网模式 |

音量模式锁定时，屏幕音量行出现描边、底部提示"音量模式 · 旋转调节"。

## 四、网页控制台

联网后浏览器访问（手机/电脑均可，需与设备同一局域网）：

- **http://radio.local**（mDNS 域名，推荐，IP 变了也不受影响）
- 或 `http://<设备IP>`（屏幕信息页 / 主页走马灯上有显示）

### 功能

- **播放控制**：播放 / 暂停 / 音量滑条 / 静音 / 上一台 / 下一台
- **电台管理**：增、删、改；名称最多约 15 个汉字（超长自动截断）
- **批量导入 / 导出**：JSON 格式，一键备份整个电台库
- **分页浏览 + 搜索**：每页 20 条，最多 200 个自定义电台

### 诊断接口（浏览器直接打开）

| 地址 | 内容 |
|---|---|
| `/api/status` | 总状态：WiFi、播放状态、音量、错误信息 |
| `/api/diag` | 详细诊断：状态机 / 缓冲 / 电平 / 解码时钟 / 重连计数 |
| `/api/events` | 最近 24 条事件（断流 / 停滞 / 重连 / 换台 / 复位原因） |
| `/api/list` | 电台库 JSON |

## 六、断流自愈机制（如何工作）

网络电台最常见的故障是"突然没声"。本固件的自愈策略：

1. **可靠判据 = 解码时钟**：只有解码器真的解出 PCM 数据，时钟才前进；6 秒不前进即判定解码僵死，强制重连音频管线；
2. **指数退避重连**：断流后 4s → 8s → 16s → 30s → 60s 间隔重试，不给服务器添堵；
3. **死地址自动跳台**：连续 4 次（约 1 分钟）一个音频字节都解不出 → 判定地址失效（403/404/下线）→ 自动切下一台，整机不会永久无声；
4. **60 秒内有声优先按临时断流处理**（只退避不清状态），避免服务器偶尔掐一次连接就把好好的台跳走；
5. **极端情况自发重启** + 重启风暴保护：连续自发重启超过 2 次仍治不好，则本次开机禁用重启、改走跳台路线。

所有自愈动作都会记入 `/api/events`，出问题可回溯。

## 七、常见问题（FAQ）

**Q：完全没声音？**
先查功放 **SD 脚是否拉高到 3.3V**（悬空=关机无声，最常见）；再串口发 `tone` 听测试音——有测试音说明硬件好，问题在网络/流地址；没测试音查接线（BCLK/LRC/DIN/共地）。

**Q：屏幕白屏但背光亮？**
① VCC 改接 **5V**（3.3V 供电不足是本项目白屏真凶）；② 排查接线，串口依次试 `tft`（重初始化）→ `tft test`（颜色自检）→ `tft scan`（频率扫描）。

**Q：屏幕颜色不对（白底黑字 / 偏红）？**
串口 `tft inv 0/1`（反色）、`tft rgb 0/1`（红蓝顺序），确认后改 `AppConfig.h` 的 `TFT_INVERT` 固化。

**Q：旋钮方向反了？**
`AppConfig.h` 里把 `PIN_ENC_A` 和 `PIN_ENC_B` 对调（或直接换线）。

**Q：找不到 radio.local？**
mDNS 部分安卓/浏览器不支持，改用设备 IP（屏幕信息页可见）。

**Q：某个台一直无声然后自动跳走了？**
该地址已失效（死地址判定生效），属预期行为。在网页控制台删除并添加新地址。

**Q：想加自己的电台？**
网页控制台"添加电台"，名称 + 流地址（m3u8 / mp3 / aac 均可）即可。
